# Development Environment

## Prerequisites
- **Node.js**: v24.12.0
- **Python**: 3.14.3
- **pnpm**: 10.32.1
- **Google Chrome**: Required for extension testing (do not use Chromium)

## One-Time Setup Checklist
- [x] Node.js, Python, and pnpm installed and verified.
- [ ] Create a dedicated Chrome profile named "YT Noter Dev" to prevent development extensions from corrupting your daily browsing storage.
